# Jean Lucas Eletricista - Site Institucional

Site profissional de uma empresa de elétrica residencial em São José dos Campos, desenvolvido com **Next.js**, **React**, **TypeScript** e **Tailwind CSS**.

## 🎯 Objetivo

Gerar solicitações de orçamento através do **WhatsApp** com foco em conversão e SEO local.

## 🛠️ Tecnologias

- **Next.js 14** - Framework React
- **TypeScript** - Tipagem segura
- **Tailwind CSS** - Estilização
- **Lucide React** - Ícones
- **Mobile First** - Design responsivo

## 📂 Estrutura do Projeto

```
src/
├── app/
│   ├── globals.css          # Estilos globais
│   ├── layout.tsx           # Layout raiz
│   └── page.tsx             # Página inicial
├── components/
│   ├── Header.tsx           # Cabeçalho com navegação
│   ├── Hero.tsx             # Seção hero
│   ├── Services.tsx         # Serviços oferecidos
│   ├── Problems.tsx         # Problemas elétricos comuns
│   ├── Differentials.tsx    # Diferenciais da empresa
│   ├── ServiceArea.tsx      # Área de atendimento
│   ├── About.tsx            # Sobre a empresa
│   ├── Testimonials.tsx     # Avaliações
│   ├── FAQ.tsx              # Perguntas frequentes
│   ├── FinalCTA.tsx         # Call-to-action final
│   ├── Contact.tsx          # Seção de contato
│   ├── Footer.tsx           # Rodapé
│   ├── FloatingWhatsApp.tsx # Botão flutuante
│   └── WhatsAppButton.tsx   # Componente reutilizável
```

## 🚀 Como Executar

### Instalação

```bash
npm install
# ou
yarn install
```

### Desenvolvimento

```bash
npm run dev
# ou
yarn dev
```

Acesse: `http://localhost:3000`

### Build

```bash
npm run build
npm start
```
